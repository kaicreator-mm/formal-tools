1 · Problem input

Paste a supported model, or load a sample. The bridge builds a checkable execution plan — nothing runs before you approve it.

Input mode

Accepted: SMT-LIB2 text (needs (assert / (check-sat)) or an LP JSON model with exactly sense ("min"|"max"), objective, variables, constraints keys. Max 64 kB (engine cap).

The LLM only proposes a method; it is admitted through the same static validation gates as the template and has no execution authority. Requires DEEPSEEK_API_KEY on the bridge host (otherwise the request fails closed with BLOCKED_PROVIDER).

Samples

Assumptions are recorded verbatim in the plan; you can edit them again on the plan screen (max 256 characters each).

A REAL DeepSeek call proposes a structured constraint model (max 8 kB text). The proposal is untrusted: it is never executed until you inspect and explicitly approve it on the next screen. Vague texts come back with clarification questions instead of a guess. Requires DEEPSEEK_API_KEY on the bridge host (otherwise: honest BLOCKED_PROVIDER).
