# Tool installation packages

**All installers are organized at** https://drive.google.com/drive/folders/1GqX-Dn42Xi_STaoWYoq4aRXi3le2WPHB.

`INDEX.json` records 10 legacy standalone files and one aggregated Linux x86_64 toolkit folder, without duplicating binary files. The complete bundle includes `artifacts/`, `wheelhouse/`, `MANIFEST.json`, `SHA256SUMS`, and `install_offline.py`; manifest: https://drive.google.com/file/d/1dLsohSIgDIhrTFqoLQrrQR3f6okcFVG3/view .

Separate Python environments may be needed: Clingo wheel is CPython 3.14 while previously uploaded pySHACL offline pack uses Python 3.13. Check JDK 21 and .NET 8 for Jena / Dafny. Runtime validation not complete.
