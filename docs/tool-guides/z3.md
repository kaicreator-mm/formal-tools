# Z3 — 简介与快速入门

## 核心用途
SMT（可满足性模理论）：将布尔与整数、数组等理论约束组合，通过 SAT/理论求解判断模型存在性。

## 架构
SMT-LIB 前端、理论求解器和 SAT 引擎；SAT 可产生模型，UNSAT 表示给定公式不可满足。

## 实现与验证方式
通过 z3 -smt2 检查 SMT-LIB 文件；可与 cvc5 对照同一问题。

## 快速入门（安装相关二进制后）
    z3 -smt2 skills/z3/examples/positive.smt2

## CLI 与 MCP 接入
上述命令是原生 CLI 示例（可能受版本、工作目录和依赖影响）。统一 CLI 可执行：
    python3 -m packages.runner run z3 --case positive
    python3 -m packages.runner run z3 --case negative
统一 MCP 通过 `run_formal_fixture(tool="z3", case="positive")` 对同一个固定 fixture 执行，**并非声称工具本身提供官方 MCP 服务**。依赖官方 Python MCP SDK v2；安装并连接服务器后才能调用。

## 安装与兼容
Z3 5.3.3 Linux 独立安装包。实际文件在 Google Drive `App/Formal-Methods/packages`，详细文件 ID 见 `packages/INDEX.json`。

## Woodpecker 使用定位
首选作为带预装依赖的 Docker Pipeline Step 中的固定工具用例；不建议修改 Woodpecker Agent 核心。参见 `docs/WOODPECKER_AGENT_INTEGRATION.md`。

## 边界与证据
检查的是编码后的公式，不是未形式化的整个业务需求。 静态文档已编写，运行验收仍为 `NOT_RUN`。
